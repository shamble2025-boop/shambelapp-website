# Shambel App - Premium Technology Website

A world-class, premium technology education platform built with Next.js 14, Tailwind CSS, and TypeScript.

## Features
- Exact Approved Pixel-Perfect UI
- Next.js App Router (SSR/SSG)
- Tailwind CSS Premium Design System
- Fully Functional Dark Mode (Persists in LocalStorage)
- Fully Functional English/Amharic Language Switcher (Persists in LocalStorage)
- Deep Search Functionality (Matches title, excerpt, category, content, tags)
- Fully Functional Newsletter API with Validation & Duplicate Checking
- Production-Ready Social Share Buttons (Twitter, Facebook, LinkedIn, Telegram, WhatsApp, Copy Link)
- Server-Side Pagination on All Articles Page
- SEO Optimized (Sitemap, Robots, OpenGraph, JSON-LD)
- Upgraded About, Contact, Help Center Pages with Accordions and Forms
- Comprehensive Legal Pages (Privacy, Terms, Cookies, Disclaimer, DMCA)
- Back-to-Top Button Functionality

## Installation
1. Run `npm install`
2. Run `npm run dev` for development
3. Run `npm run build` for production

## Deployment (Hostinger)
1. Push code to GitHub.
2. In Hostinger hPanel, go to Advanced > Git and clone repo.
3. Create a Node.js app (v18+) in Advanced > Node.js.
4. Set Start Command: `npm start`
5. Add custom domain.
